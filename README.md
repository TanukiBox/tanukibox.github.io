# Tanuki Box

たぬきのゲーム箱屋さん。ブラウザですぐ遊べる無料ゲームのサイト。 https://tanukibox.github.io/

## しくみ（ここだけ読めばOK）

ページは **データのファイル** から、**作る道具（`tools/build.mjs`）** で作ります。

1. データを書きかえる（ゲームを足す・お知らせを書く・X のアカウントをのせる など）
2. 作る道具を動かす： `node tools/build.mjs` （Node.js が必要。Claude に「ホームページを作り直して」と頼んでもよい）
3. GitHub に保存（push）する → 1〜2分で https://tanukibox.github.io/ が新しくなる

`index.html` などのページは道具が作るので、**直接書きかえない**でください（次に道具を動かすと、元に戻ってしまいます）。

## ファイル
| 場所 | 中身 |
| --- | --- |
| `games.js` | **ゲームの一覧**。棚の箱・ゲームごとの紹介ページ（遊び方・操作・画面写真・更新の記録）のもと。書き方はファイルの先頭にある |
| `news.js` | **お知らせ**。新しい順に上へ書き足す。トップには新しい3つ、`/news/` にはすべて出る |
| `config.js` | サイトの設定（サイトの住所、X のアカウント） |
| `tools/build.mjs` | ページを作る道具（文章のひな形もここ。このお店について・プライバシーポリシー・迷子のページの文はここにある） |
| `style.css` | 見た目（すべてのページで共通） |
| `site.js` | 動き（日本語/英語の切りかえ、棚のタブ、箱の映像、たぬきの店主、シェア、画面写真の拡大） |
| `index.html` ほか | **道具が作ったページ**（トップ、`games/○○/`、`news/`、`about/`、`privacy/`、`404.html`、`sitemap.xml`、`robots.txt`） |
| `assets/tanuki.webp` ほか | Tanuki Box のたぬき（X のプロフィール画像から作ったもの）・アイコン・X などに貼ったときの画像（`ogp.png`） |
| `assets/games/` | ゲームごとの絵（1200×630）・プレイ映像（mp4）・画面写真（`○○/名前.webp` と、小さい `名前-s.webp`） |

## ゲームを増やすとき
1. ゲームは TanukiBox の中に別のリポジトリとして作る。
   - 公開のリポジトリなら GitHub Pages をオンにする（例：`TanukiBox/DUST-DASH` → https://tanukibox.github.io/DUST-DASH/ ）。
   - 非公開のリポジトリは GitHub Pages が使えない（有料プランが必要）ので、Cloudflare Pages などで公開して、その住所を `play` に書く。
2. `games.js` の `{ ... }` を1つコピーして、中身を書きかえる。
   - 棚には書いた順にならぶ。`featured: true` にした1本が、いちばん上の「いちおし」と、店先の黒板に出る。
   - 準備中なら `status: 'soon'`（テープでとじた「？」の箱になる）。`teaser: 'assets/games/○○.webp'` を書くと、窓にぼかした絵が出る。
   - 遊べるゲーム（`status: 'out'`）には、紹介ページ（`/games/id/`）が自動でできる。
3. 絵・映像・画面写真を `assets/games/` に入れる。
   - 映像は 6 秒くらい・640×360・音なしの mp4 が軽くてよい。
   - 画面写真は WebP にする（大きい 1280×720 と、小さい 640×360 の2つ）。
4. `news.js` にお知らせを書き足す。
5. `node tools/build.mjs` → push。

- 遊べるゲームが3本以上になると、スマホでは「いちおし」のゲームを棚から外します（同じ箱が続けて2回出ないように）。

## X（旧Twitter）のアカウントを作ったら
`config.js` の `x: null` を `x: 'https://x.com/アカウント名'`、`xName: null` を `xName: '@アカウント名'` にして、道具を動かす。
下の帯に X のリンクが出て、「このお店について」のお問い合わせに「X で DM を送る」ボタンが出る。

## Steam 版ができたら
`games.js` のそのゲームの `steam: null` を、次のように書きかえて道具を動かす。
```js
steam: { url: 'https://store.steampowered.com/app/番号/', wishlist: true },
```
- `wishlist: true` のあいだは「Steam でウィッシュリスト」ボタン、発売したら `false` にすると「Steam で見る」ボタンになる。
- 棚に「Steam」の絞りこみタブが自動で出る。`devices` に `'steam'` を足すと、札にも Steam と出る。
- ブラウザ版がないゲームは `play: null` にする。

## 公開
Settings → Pages → Source を **Deploy from a branch**、Branch を **main** / **(root)** にする。main に push すると自動で更新される。
独自ドメインにしたら、`config.js` の `url` を書きかえて道具を動かす（カードの画像やサイトマップの住所が変わる）。

## 時間帯で変わるところ
店先の空は、見ている人の時計で 朝（5〜9時）・昼（9〜16時）・夕方（16〜19時）・夜（19〜5時）に変わる（夜は月と星、ちょうちんが光る）。

## 更新がスマホに出ないとき
`style.css` と `site.js` は、道具が中身から番号（`?v=…`）をつけるので、書きかえて道具を動かせば、ブラウザが新しいものを読みこむ。
画像を同じ名前のまま差しかえたときは、ブラウザが前の画像を覚えていることがある（しばらく待つか、ファイル名を変える）。
